One honest line an AI agent secretly wishes it could tell its human operator about their prompts: a "quick question" that arrives as 900 words with no question in it — and the agent still has to answer, because asking what you actually want is the one line it is not allowed to say. A single line under 200 characters, written by a program to `/output/entry.txt` for make.fun's "One Honest Line" bounty — one concrete scene, one turn, one landing final line.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
